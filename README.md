## What we make

We ship desktop applications that do their work on the user&rsquo;s machine. No cloud round-trips, no account required, no telemetry. The category we serve is people whose source material has reasons to stay where it was authored: researchers under IRB, journalists with confidential sources, attorneys with privileged correspondence, clinicians with case notes, writers under embargo.

Each product is a single purchase with a perpetual license and runs offline after install.

## Products

### TASS: Text Analysis for Social Scientists

Dictionary-based text scoring that is deterministic and provenance-first: every run writes a manifest with versions, hashes, and citations. The free, open-source Community Edition (Apache-2.0) carries the engine, CLI, and MCP server; the GUI Edition adds a no-code workbench with inferential statistics, publication charts, and APA-ready reports.

→ [usetass.app](https://usetass.app) · [github.com/SIM-DAD/tass](https://github.com/SIM-DAD/tass)

### Resero: Workbench for sensitive material

A desktop workbench for anyone whose material must stay on their own machine. Per-file secure tagging, on-demand encryption at rest, and local-only AI routing for protected files. Bundles the Ibis, Lector, Orator, and Velamen applications, each also sold standalone; TASS is its companion analysis instrument, a separate product.

→ [useresero.app](https://useresero.app)

### Ibis: Automatic local transcription

Watches a folder and auto-transcribes audio using local Whisper models. No cloud, no API keys. Originals are kept; encryption is non-destructive and optional.

→ [useibis.app](https://useibis.app)

### Lector: Manuscript editor with read-aloud

Distraction-free Markdown manuscript editor with source and visual modes and built-in read-aloud for proofing by ear. Offline neural voices are on the roadmap as a free update.

→ [uselector.app](https://uselector.app)

### Orator: Document-to-narrated-video

Turns Markdown documents into narrated, camera-ready videos with local text-to-speech. One pipeline: parse, narrate, render slides, compose MP4.

→ [useorator.app](https://useorator.app)

### Velamen: Data minimization aid

Helps strip identifying data from research material before it is shared. Built with the intention to support adherence to privacy standards; it does not promise compliance outcomes. Name-your-price, free software; the engine, `@simdad/wordlist-core`, is open source (Apache-2.0) on GitHub and npm.

→ [github.com/SIM-DAD/wordlist-core](https://github.com/SIM-DAD/wordlist-core)

## License posture

Application binaries are commercial. The TASS Community Edition, the open lexicons ([tass-lexicons](https://github.com/SIM-DAD/tass-lexicons)), and the Velamen engine are open source. Encryption across the suite uses the [age format](https://age-encryption.org) with OS-native key storage; the user holds the keys and can recover their data without us.
