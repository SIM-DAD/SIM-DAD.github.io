Radio Ad Script

30-second two-column production script for TASS.

Format: 30-Second Production Script (Two-Column)

Client: SIM DAD LLC — TASS

Target audience: Academic researchers, graduate students

AIDA structure labeled in brackets

TIME PRODUCTION (LEFT) AUDIO (RIGHT)
0:00 SFX: KEYBOARD TYPING, FRUSTRATED SIGH
0:02 MUSIC: MINIMAL PIANO, LOW, STEADY [ATTENTION] (Tired, relatable) You've got the data. You've got the research question. But every time you open the script, it's another error message.
0:08 SFX: ERROR CHIME
0:09 MUSIC: SHIFTS TO WARMER, CONFIDENT TONE [INTEREST] (Reassuring) What if you didn't need the script at all?
0:12 [DESIRE] TASS is a desktop text analysis tool built for researchers who don't code. Import your data. Pick a dictionary. Get results with effect sizes, confidence intervals and APA-ready tables — all on your machine, completely offline.
0:22 Built by a professor. Designed for the rest of us.
0:25 MUSIC: RESOLVES [ACTION] Download the free trial at U-S-E-T-A-S-S dot app. No code. No cloud. Just answers.
0:30 SFX: SOFT CLICK (APP OPENING)

Total running time: 30 seconds

Estimated word count: ~95 words (within 30-second guideline)

Production note: This script can be recorded using SIM DAD's own Orator or Lector products as a proof-of-concept demo — voice-cloned narration from a 10-second reference clip.
