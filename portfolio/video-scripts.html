Lab 7 — Production Track Alternate

Social Video Scripts

Three connected TikTok/Reels scripts demoing TASS.

Format: Three connected short-form scripts (TikTok/Instagram Reels)

Series title: "Code vs. No Code"

Target audience: Graduate students and early-career researchers

Production tool: Remotion (programmatic video) or Orator (narrated)

Video 1 of 3: "The Import"

Duration: 45 seconds

Hook: Side-by-side comparison — how researchers import data now vs. with TASS

TIME VISUAL NARRATION / TEXT OVERLAY
0:00-0:03 Split screen. Left: VS Code with R terminal. Right: TASS welcome screen. TEXT: "Importing a CSV for text analysis"
0:03-0:12 Left: Typing library(tidyverse), read_csv("data.csv"). Error: "package 'tidyverse' not found." More typing. NARRATION: "Step one: install your packages. Oh wait, they didn't install. Let's try again."
0:12-0:18 Left: Stack Overflow tab opens. Right: User drags CSV file onto TASS window. Data appears instantly. NARRATION: "Or... just drag and drop."
0:18-0:30 Right side expands to full screen. TASS shows data preview with column types detected. NARRATION: "TASS reads your CSV, detects your columns and is ready to analyze. No packages. No debugging. No Stack Overflow."
0:30-0:40 Clean product shot. TASS logo + "usetass.app" TEXT: "Text analysis without the terminal. Free trial — link in bio."
0:40-0:45 SIM DAD logo TEXT: "Your data deserves better tools."

Video 2 of 3: "The Analysis"

Duration: 40 seconds

Hook: Running a sentiment analysis — code vs. clicks

TIME VISUAL NARRATION / TEXT OVERLAY
0:00-0:03 Split screen returns. Same setup. TEXT: "Running sentiment analysis on 1,000 texts"
0:03-0:12 Left: 15 lines of R code — loading dictionary, tokenizing, scoring, grouping. NARRATION: "Fifteen lines of code. Hope you spelled everything right."
0:12-0:22 Right: TASS user clicks "Analyze" panel, selects AFINN dictionary from dropdown, clicks "Run." Progress bar. Results appear in structured viewer. NARRATION: "Two clicks. Same dictionary. Same math. Same results."
0:22-0:32 Right side full screen: structured output showing descriptive stats, assumption checks, inferential tests, effect sizes. NARRATION: "Effect sizes, confidence intervals, Levene's test, Shapiro-Wilk — all computed automatically. APA-formatted. Export-ready."
0:32-0:40 Product shot. TASS logo + URL. TEXT: "TASS. Free 30-day trial. No code required."

Video 3 of 3: "The Export"

Duration: 35 seconds

Hook: Getting results into a manuscript

TIME VISUAL NARRATION / TEXT OVERLAY
0:00-0:03 Split screen. Left: R console. Right: TASS. TEXT: "Getting your results into a paper"
0:03-0:10 Left: User copies numbers from console, pastes into Word table, manually formats. NARRATION: "Copy. Paste. Format. Pray you didn't transpose a number."
0:10-0:18 Right: TASS user clicks "Export," selects Excel. File opens showing pre-formatted APA table with method sheet. NARRATION: "Or click Export. APA table. Method sheet documenting your entire pipeline. Reproducibility sidecar included."
0:18-0:28 Right side full screen: Excel file with APA headers, properly formatted p-values (no leading zero, three decimals), effect size labels. NARRATION: "Every p-value formatted correctly. Every test documented. Every decision recorded. Drag it into your manuscript and move on to the discussion section."
0:28-0:35 Series recap: all three TASS screens side by side, then product logo. TEXT: "Import. Analyze. Export. usetass.app"

Series production notes:

  • All three videos use the same split-screen visual language for brand consistency
  • Screen recordings can be captured from actual TASS running on Windows
  • Narration recorded with Orator (voice-cloned) or Lector (preset voice)
  • Programmatic composition possible with Remotion for consistent timing and transitions
  • Each video works standalone but the series builds a complete narrative arc
