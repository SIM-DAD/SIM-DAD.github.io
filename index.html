Who we are

About
SIM DAD LLC.

SIM DAD LLC builds local-first AI software tools for researchers, academics, and domain experts who need professional-grade capabilities without coding overhead, cloud dependencies, or subscription fees. Our products run entirely on your machine — no data leaves your device, ever.

Our products are Ibis — local AI transcription for Windows — TASS, a no-code text analysis desktop app targeting launch in May 2026, and Lector, a distraction-free writing environment with read-aloud and voice cloning built in.

The research track record behind our software includes a $1.59M NSF-funded program, formal data-access agreements with Riot Games and VRChat, and large-scale NLP pipelines across hundreds of millions of records. We build the software we wished existed while doing that research.

Our products

Software & Projects

Local-first. One-time pricing where possible. Built to the standard of tools we would use ourselves.

01
Ibis
Local AI · Windows Desktop · v1.0 Complete · Launching Soon — $24

Ibis watches a folder on your Windows PC and transcribes every audio file automatically using on-device AI. Powered by Whisper large-v3-turbo. 99 languages. No cloud. No subscription. One-time purchase. v1.0 is built and in pre-launch.

Product site →
02
TASS
Text Analysis · Windows Desktop · Launching May 2026 — $49/yr

TASS is a native Windows desktop app for dictionary-based text analysis — no Python, R, or command line required. Features group comparisons (t-test, ANOVA), publication-quality visualizations, and APA citation blocks built in. Ships with eight open-licensed dictionaries. Built for social scientists, journalists, and domain experts.

Product site →
03
Lector
Writing Tool · Windows & macOS · Coming Soon — $29

Lector is a distraction-free writing environment with read-aloud built in. Write your draft, then hear it read back word by word. Voice cloning via F5-TTS lets you build a voice profile from thirty seconds of audio. Completely local — no cloud processing, no account required.

Product site →
04
The Cage
Next.js · PostgreSQL · Docker · SSO · Institutional Deployment

An equipment reservation and QR-based checkout system currently deployed at SIUE Mass Communications. Dual-database architecture, Docker Compose, Microsoft Entra SSO, and Snipe-IT integration. The institutional deployment serves as the reference implementation for a future multi-tenant SaaS product.
